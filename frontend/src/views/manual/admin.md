# 管理员使用手册

平台提供 Web 管理后台，用于维护 **中台业务资源**（地图、模型、媒体、参数配置）以及平台自身的用户、角色、菜单、日志与安全配置。

> 园区、设备、任务、路线由 `business/` 业务平台承载；设备接入、指令下发与服务编排也在业务平台完成，中台不再提供对应菜单与接口。

## 1. 登录

打开浏览器访问中台管理后台，使用中台账号登录：

| 字段   | 说明       |
| ------ | ---------- |
| 用户名 | 管理员账号 |
| 密码   | 管理员密码 |

登录成功后进入首页仪表盘，左侧菜单为一级平铺展示：首页、「系统管理」、地图管理、模型管理、媒体资源、参数配置。

> 密码连续输错达到上限、或超过密码有效期时会提示锁定/修改密码，按提示处理即可。

## 2. 首页仪表盘

首页展示四张统计卡片与一张图表：

| 区块     | 说明                                  |
| -------- | ------------------------------------- |
| 地图数量 | `dog_map` 中未删除的地图版本条数      |
| 模型数量 | `dog_model` 中未删除的模型条数        |
| 媒体数量 | `dog_media` 中未删除的媒体条数        |
| 参数配置 | `dog_config` 中未删除的配置条数       |
| 数量统计 | 按「上周 / 本周」切换的四类资源柱状图 |

卡片上的百分比为 **周同比**（本周新增 vs 上周新增），折线为本周每日新增数量。

## 3. 通用列表操作

以下页面（地图、模型、媒体、参数配置）操作方式一致：

| 操作 | 说明                                                                                                       |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| 搜索 | 顶部查询表单，填写条件后点「搜索」，点「重置」清空条件并刷新                                               |
| 新增 | 右上角「新增」按钮，弹窗填写表单后提交                                                                     |
| 修改 | 表格行「修改」，弹窗中修改字段后提交                                                                       |
| 删除 | 表格行「删除」，二次确认后执行（**软删除**，对应业务记录不再展示）                                         |
| 分页 | 表格底部切换页码 / 每页条数，默认每页 10 条                                                                |
| 查询 | 顶部统一查询栏（与用户管理一致）：常用条件常显，点右侧箭头展开「更多条件」，点「搜索」查询、点「重置」清空 |

统一约定：

- 列表默认按 **创建时间倒序** 排列。
- 时间字段统一按 **北京时间（UTC+8）** 展示，格式 `YYYY-MM-DD HH:mm:ss`。
- 数字型字段（如文件大小）使用数字输入框，避免提交字符串导致接口报错。

### 3.1 数据权限（地图）

地图按 **创建者** 做行级隔离：普通用户只能看到、修改、删除自己创建的地图，访问他人数据返回「不存在」；管理员（内置角色 `sysadm`，角色编码 `110`）可查看和操作全部数据。「所属用户ID」由服务端根据登录 token 自动写入，无需也不允许在表单中填写。

模型、媒体、参数配置为共享资源，不做用户级隔离。

## 5. 媒体资源

| 字段     | 说明           |
| -------- | -------------- |
| 媒体名称 | **必填**       |
| 媒体类型 | 图片 / 视频等  |
| 文件路径 | 媒体文件路径   |
| 文件大小 | 字节数（数字） |
| 备注     | 说明           |

查询条件：媒体名称、媒体类型、设备编号；「更多条件」中可按巡检计划、来源、创建时间范围过滤。

设备回传的记录（来源「AI巡检」）会带上设备编号、计划、航点与采集时间，行操作里的
「预览」直接看图片（`GET /api/dogMedia/{id}/image`）。手工新增的记录没有落盘文件，
预览会提示「没有可预览的图片文件」。

图片从哪来：板端每轮航点 AI 识别固定保存 N 帧到 `/media/media-data/picture`，
在**设备管理**页面对某台设备点「同步媒体」，设备客户端才会把图逐张回传上来
（上传成功即删除板端文件）。目录与帧数在「参数配置」里改（见下一节）。

## 6. 参数配置

「同步媒体」相关的两个预置项（迁移时自动写入，改完最多 1 分钟生效）：

| 配置名称            | 默认值                        | 说明 |
| ------------------- | ----------------------------- | ---- |
| `media_picture_dir` | `/media/media-data/picture`   | 板端 AI 存证目录（写图与回传必须是同一路径） |
| `media_frames`      | `3`                           | 每个航点固定保存/回传几帧（1~10） |

| 字段     | 说明     |
| -------- | -------- |
| 配置名称 | **必填** |
| 配置值   | 配置内容 |
| 描述     | 说明     |

查询条件：配置名称；「更多条件」中可按创建时间范围过滤。

## 7. 地图管理

地图管理以「地图包」的方式维护，新增时直接上传 `.zip` 地图包（落盘到 `data/device_uploads/maps/`）。

| 字段             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| 地图名称         | **必填**，地图显示名称                                       |
| 地图类型         | 下拉选择：离线地图 / 在线地图                                |
| 园区编码 / 名称  | 归属业务园区（机器人回传时自动写入）                         |
| 设备编号         | 上报该地图的设备编号（机器人回传时自动写入，手工上传可留空） |
| 基线版本         | 版本号，例如 `v1.0`                                          |
| CRS              | 坐标参考系说明                                               |
| 文件名称         | 上传的地图包文件名（自动写入）                               |
| 文件格式         | 地图包格式，目前仅支持 `zip`                                 |
| 文件大小（字节） | 地图包大小（自动写入）                                       |
| 描述信息         | **必填**，地图说明                                           |
| 创建时间         | 记录创建时间                                                 |

| 操作   | 说明                                                                     |
| ------ | ------------------------------------------------------------------------ |
| 新增   | 「新增」→ 填写地图名称 / 类型 / 描述 → 「选取文件」上传 `.zip` → 确认    |
| 修改   | 弹窗中可改名称 / 类型 / 描述；如需更换地图包，重新上传 `.zip` 后确认即可 |
| 发布   | 将草稿 / 部分标定版本推进为「已发布」，并记录发布时间                    |
| 新版本 | 基于当前版本派生下一个版本并立即发布                                     |
| 删除   | 二次确认后软删除记录（原地图包文件保留在磁盘上）                         |
| 地图   | 打开地图预览 / 编辑弹窗，可缩放拖动查看，并用橡皮擦擦除栅格噪点          |

> 操作列固定显示「地图 / 修改 / 删除」，其余「发布」「新版本」收进行尾的「更多」下拉菜单（与设备管理保持一致），避免按钮堆满一列。

### 7.1 地图预览与橡皮擦

「地图」按钮打开的弹窗同时承担预览与编辑：

- **浏览**：滚轮缩放、按住左键拖动平移，工具栏可快速复位到 100% 或适应窗口。
- **橡皮擦**：切到橡皮擦后可调笔刷像素直径（1–120 px），在图上涂抹即擦除噪点；
  支持「撤销」单笔与「放弃」全部未保存笔画。
- **擦除值**：`254`（可通行，默认）适合把自由空间里的孤立黑点擦白；
  `205`（未知）适合把无法判定区域的干扰像素擦成未知。
- 保存后后端只改写编辑版栅格（包内有 `map_edit/map.pgm` 时改它，否则改
  `model.pgm` / `map.pgm`），根目录的建图原始 `map.pgm` 不动，yaml 与其余条目
  原样保留，分辨率 / 原点 / 版本号不变，`map_hash` 按新包重算，因此**已下载过
  该图的设备需要重新同步地图**。

> 只有「草稿」「部分标定」版本可编辑；「已发布」「已归档」版本请在列表里先派生
> 「新版本」（新版本为草稿），再对新版本擦除，避免改动正在使用的基线。

### 7.2 下发到狗体

擦除只在**中台**改了地图包，机器人本体上的文件不会自动更新。要让任务用上新地图，
需要把地图下发回狗体：

- 预览弹窗底部「下发到狗体」按钮，或保存擦除后弹窗里的「立即下发」；
- 地图列表行尾「更多 → 下发到狗体」。

链路：中台 → 业务平台 → 设备客户端 → 本体文件服务（覆盖栅格并读回校验）→
4030 重新载图。本体地图目录里通常有两份栅格：根目录 `map.pgm` 是建图原始地图，
`map_edit/map.pgm` 是遥控器编辑后的地图。平台预览、擦除与下发都以 `map_edit/`
为准；本体存在 `map_edit/` 时只覆盖 `map_edit/map.pgm` / `map_edit/map.yaml`，
**原始 `map.pgm` 不会被改**；没有 `map_edit/` 的老固件才退回根目录。
`map.pcd` / `map.geojson` / `nav_paths` 不会被改，已有路线不受影响。

> 下发前请确认：设备在业务平台**在线**、**没有在执行任务 / 建图**，且这张地图已经
> 导入业务平台（园区地图基线里能看到）。设备离线、本体上没有对应地图目录、或地图
> 没导入过时，接口会直接报错（不会“看起来成功”）。
>
> 下发成功后中台列表里的 `map_hash` 与业务平台、目标设备上的地图包一致；如果设备
> 正在跑任务，请先结束任务再下发，否则会提示「正在执行任务」。

> 查询条件：地图名称、地图类型（下拉）、基线状态（下拉）、文件名称、设备编号；「更多条件」中可按创建时间范围过滤。

> 坐标系 `frame_id` 与覆盖楼层在机器人回传链路里并不上报（业务平台 `mapInfo` 不含这两个字段），中台地图页不再展示 / 填写；后端 `dog_map.frame_id` / `floors` 列与接口字段仍保留，业务平台补齐回传后可直接生效。

> 上传后由后端优先解析本体回传的编辑版 `map_edit/map.pgm` / `map_edit/map.yaml`（没有时才用 `model.pgm` / `model.yaml`），回写分辨率、原点、栅格尺寸与 SHA-256（`map_hash`），表单值与包内容冲突会被拒绝。

## 9. 常见问题

**列表里没有刚创建的数据**
：页面按创建时间倒序并分页展示，确认查询条件是否残留；确认提交时接口返回 `code = 10200`。

**删除后数据还在数据库里**
：资源类数据统一使用软删除（`is_deleted = 1`），接口与页面都不会再展示该记录。

**首页图表没有数据**
：统计来自 `dog_map` / `dog_model` / `dog_media` / `dog_config` 的真实记录，新增对应资源后即可看到数据。

**园区 / 设备 / 任务 / 路线 / 指令 / 服务去哪了**
：这些业务已迁移到 `business/` 独立业务平台（默认端口 3100），请在业务平台维护。
