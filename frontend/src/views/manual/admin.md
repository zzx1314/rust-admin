# 管理员使用手册

平台提供 Web 管理后台，用于维护 **机器狗业务数据**（设备、任务、路线、模型、媒体、指令、配置、服务）以及平台自身的用户、角色、菜单、日志与安全配置。

## 1. 登录

打开浏览器访问管理后台，使用管理员账号登录：

| 字段   | 说明       |
| ------ | ---------- |
| 用户名 | 管理员账号 |
| 密码   | 管理员密码 |

登录成功后进入首页仪表盘，左侧菜单为一级平铺展示：首页、「系统管理」、地图管理、设备列表、任务管理、路线管理、模型管理、媒体资源、指令管理、参数配置、服务管理、园区列表。

> 密码连续输错达到上限、或超过密码有效期时会提示锁定/修改密码，按提示处理即可。

---

## 2. 首页仪表盘

首页展示四张统计卡片与两张图表：

| 区块         | 说明                                                     |
| ------------ | -------------------------------------------------------- |
| 设备数量     | `dog_device` 中未删除的设备条数                          |
| 任务数量     | `dog_task` 中未删除的任务条数                            |
| 模型数量     | `dog_model` 中未删除的模型条数                           |
| 路线数量     | `dog_route_library` 中未删除的路线条数                   |
| 数量统计     | 按「上周 / 本周」切换的设备/任务/模型/路线柱状图         |
| 设备统计     | 按设备类型汇总的柱状图                                   |

> 当前版本后端只实现了总量统计；`数量统计` 与 `设备统计` 的聚合接口尚未实现，图表会显示为 0 / 空数据。

## 3. 通用列表操作

以下页面（园区、地图、设备、任务、路线、模型、媒体、指令、参数配置）操作方式一致：

| 操作     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 搜索     | 顶部查询表单，填写条件后点「搜索」，点「重置」清空条件并刷新 |
| 新增     | 右上角「新增」按钮，弹窗填写表单后提交                       |
| 修改     | 表格行「修改」，弹窗中修改字段后提交                         |
| 删除     | 表格行「删除」，二次确认后执行（**软删除**，数据仍在库中）   |
| 分页     | 表格底部切换页码 / 每页条数，默认每页 10 条                  |
| 查询     | 顶部统一查询栏（与用户管理一致）：常用条件常显，点右侧箭头展开「更多条件」，点「搜索」查询、点「重置」清空 |
| 下拉条件 | 状态下拉等选项在所有页面保持一致（如设备状态 在线 / 离线，指令状态 待下发 / 已下发 / 成功 / 失败） |

统一约定：

- 列表默认按 **创建时间倒序** 排列。
- 时间字段统一按 **北京时间（UTC+8）** 展示，格式 `YYYY-MM-DD HH:mm:ss`。
- 数字型字段（如模型 ID、文件大小）使用数字输入框，避免提交字符串导致接口报错。

### 3.1 数据权限（园区 / 地图 / 设备 / 任务）

园区、地图、任务按 **创建者** 做行级隔离，设备按 **用户绑定** 隔离：

- 普通用户只能看到、修改、删除自己创建的园区 / 地图 / 任务，访问他人数据返回「不存在」。
- 地图以 `.zip` 地图包上传，不再强制挂在园区下；如果填写 / 指定园区，则必须是自己的园区，否则会提示园区不可访问。
- 设备需先绑定到当前用户才会出现在设备列表；任务填写的设备 ID 也必须是已绑定设备。
- 普通用户可以认领未被任何人绑定的设备；已绑定的设备只能由管理员分配给其他用户。
- 管理员（内置角色 `sysadm`，角色编码 `110`）可查看和操作全部数据。
- 「所属用户ID」由服务端根据登录 token 自动写入，无需也不允许在表单中填写。

## 4. 设备列表

维护机器狗设备档案。

| 字段       | 说明                       |
| ---------- | -------------------------- |
| 设备 ID    | 设备唯一标识（**必填**）；通常由设备端从硬件信息（序列号 / eMMC CID / MAC 等）自动派生 |
| 设备类型   | 设备型号分类               |
| 设备状态   | `online` 显示为「在线」，其它值原样展示；新增时默认 `offline`，设备接入后会由心跳自动更新 |
| IP 地址    | 设备通信地址               |
| 设备型号   | 型号名称                   |
| 速度/高度  | 设备上报的速度、高度       |
| 剩余电量   | 电量（文本）               |
| 航向/位置  | 航向角、当前位置           |
| 绑定用户   | 该设备已绑定的用户；`未绑定` 表示还没分配给任何人 |
| 创建时间   | 记录创建时间               |
| 通信时间   | 最近一次通信时间           |

查询条件：设备 ID（模糊）、设备类型（模糊）、状态（下拉：在线 / 离线）；「更多条件」中可按开始时间 / 结束时间过滤创建时间。

> 设备状态、通信时间除页面编辑外，也会由设备端 WebSocket 心跳自动回写（`online` + `comm_time` + 速度/高度/电量/航向/位置）；设备断开后自动置回 `offline`。

> 新注册的设备默认为“未绑定”，只有绑定了该设备的用户才能在其设备列表看到它；管理员不受限制。

### 4.1 绑定用户（在设备列表内完成）

设备绑定不再单独占用菜单，直接在设备列表的「绑定用户」列和行操作里维护：

| 操作 | 说明 |
| ---- | ---- |
| 查看 | 「绑定用户」列展示该设备当前绑定的用户，`未绑定` 表示还没有归属 |
| 绑定 | 管理员点击行内「绑定用户」，在弹窗选择用户后点「绑定」；一个设备可绑定多个用户 |
| 解绑 | 弹窗内「已绑定」列表可逐个解绑；普通用户只能解绑自己（行内「解绑」） |

> 普通用户只能认领尚未被绑定的设备；已绑定的设备需由管理员绑定。任务中填写的设备 ID 必须是当前用户已绑定的设备。

## 9. 指令管理

记录下发给设备的指令及其执行结果。

| 字段     | 说明                                   |
| -------- | -------------------------------------- |
| 指令名称 | **必填**                               |

## 12. 地图管理

地图管理以「地图包」的方式维护，新增时直接上传 `.zip` 地图包（落盘到 `data/device_uploads/maps/`）。

| 字段             | 说明                                                     |
| ---------------- | -------------------------------------------------------- |
| 地图名称         | **必填**，地图显示名称                                   |
| 地图类型         | 下拉选择：离线地图 / 在线地图                            |
| 文件名称         | 上传的地图包文件名（自动写入）                           |
| 文件格式         | 地图包格式，目前仅支持 `zip`                             |
| 文件大小（字节） | 地图包大小（自动写入）                                   |
| 描述信息         | **必填**，地图说明                                       |
| 创建时间         | 记录创建时间                                             |

| 操作 | 说明 |
| ---- | ---- |
| 新增 | 「新增」→ 填写地图名称 / 类型 / 描述 → 「选取文件」上传 `.zip` → 确认 |
| 修改 | 弹窗中可改名称 / 类型 / 描述；如需更换地图包，重新上传 `.zip` 后确认即可 |
| 删除 | 二次确认后软删除记录（原地图包文件保留在磁盘上） |

> 查询条件：地图名称、地图类型（下拉）、文件名称；「更多条件」中可按创建时间范围过滤。

## 14. 常见问题

**新增时报「模型ID必填」**
：路线管理必须选择/填写已存在的模型 ID，先在「模型管理」中创建模型。

**列表里没有刚创建的数据**
：页面按创建时间倒序并分页展示，确认查询条件是否残留；确认提交时接口返回 `code = 10200`。

**删除后数据还在数据库里**
：平台统一使用软删除（`is_deleted = 1`），接口与页面都不会再展示该记录。

**设备显示"离线"，但设备是开着的**
：后端按客户端 WebSocket 心跳刷新状态；设备断网/服务重启后客户端会自动重连（指数退避），恢复后状态会重新变为「在线」。若长时间离线，检查客户端日志中的重连记录与网络策略。

**首页图表没有数据**
：`数量统计` / `设备统计` 所需的聚合接口尚未实现，属当前版本已知限制。
